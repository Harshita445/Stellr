# Stellr — Product Vocabulary

## Official Labels (do not regress)

| Old (legacy / internal) | Final display label | Scope |
|---|---|---|
| Visible Stars | Your People | Dashboard card, section headings |
| Constellations | Your Groups | Dashboard card, page h1, stat chip, empty states, nav labels |
| Create Constellation | Create Group | Button labels |
| Constellation (page context) | Group | Group detail page h1, error/empty messages |
| Constellation | Stellr | Global brand / page title |

## Unchanged

- **Stars** — individual-person visual metaphor inside the constellation visualization (glowing dots, connecting lines). Only section/card labels changed, not the illustration language.
- **Windows** — free-time windows in availability engine.
- **Alignment** — overlap/schedule comparison feature.
- **Groups** — backend data model (`groups` table, group creation/membership, API routes) retains its internal name.

## Tagline

- **Everywhere:** "Your people. Your time. Aligned." — dashboard header, page `<title>`, and any one-line product description.

## Supporting Copy (dashboard cards)

- **Your People card:** "People you can see are free right now"
- **Your Groups card:** "Compare schedules and find shared time"
